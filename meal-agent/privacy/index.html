meal-agent privacy policy

Last updated: 26 September 2026

meal-agent is a personal tool used only by its author, Luke Griffith, with his own accounts. There are no other users.

What data it accesses

With my explicit permission, meal-agent reads the following from my own Google Health account, read-only: steps, weight, body fat and calories burned.

How the data is used

The data is used only to produce my own weekly nutrition and training summary. It is not used for advertising, profiling or any other purpose.

Where the data is stored

Data is processed and stored on my own Raspberry Pi and in my own Google Drive. It is not sold, shared with or transferred to any third party.

Google API Services User Data Policy

meal-agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time from Google Account permissions. Locally stored data is deleted on request by removing it from the Pi.
